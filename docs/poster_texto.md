# NetLearn Battle

**Autor:** Gabriel Souza

**Objetivo:** jogo educativo de redes em Python e Flask.

**Tecnologias:** Python, Flask, JSON, ipaddress, sockets TCP, unittest e Robot Framework.

**Funcionalidades:** autenticação, níveis IPv4/IPv6/ACL, score, ranking, histórico, estatísticas, treino e TCP.

**Limitações:** JSON não suporta muitos utilizadores em simultâneo; TCP é académico e simples.
